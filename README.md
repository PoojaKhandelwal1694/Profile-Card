# Profile Card UI Design

This project is a simple and attractive Profile Card UI created using HTML and CSS. The design showcases a user profile with a profile picture, personal information, social media icons, action buttons, and social engagement statistics. 



## Features

* Modern profile card design
* Circular profile image
* Social media icons using Font Awesome
* Subscribe and Message buttons
* User engagement statistics
* Clean and visually appealing layout

## Technologies Used

* HTML
* CSS
* Font Awesome Icons


## How to Run

1. Download or clone the repository.
2. Make sure the profile image (`p8.PNG`) is in the project folder.
3. Open `index.html` in any web browser.

## User Interface Components

The profile card includes:

* Profile picture
* Professional title
* College and academic information
* Social media links/icons
* Subscribe button
* Message button
* Likes, comments, and share statistics
